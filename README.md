# ClaudeSWEDev

A workspace of software projects built with Claude in cloud sessions and reviewed through pull requests.

## How it works
1. Open an issue (or just ask Claude) describing the idea.
2. Claude opens a design-doc PR for the project. Review and approve it.
3. Claude builds it story by story: one branch and one PR per story, with CI and a code review write-up.
4. You review and merge.

See [CLAUDE.md](CLAUDE.md) for the full working agreement and Definition of Done.
