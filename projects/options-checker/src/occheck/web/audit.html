How to export your trades from Interactive Brokers
  1. In the IBKR Portal, open Performance & Reports, then Flex Queries.
  2. Create an Activity Flex Query. Add the Trades section with at least: Asset Class, Symbol, Underlying Symbol, Multiplier, Strike, Expiry, Put/Call, Trade ID, Date/Time, Quantity, Trade Price, IB Commission, Open/Close Indicator, Notes/Codes.
  3. Set the format to CSV, run it for the period you want, and download the file.

    Educational tool, not financial advice. Bid-ask spreads, dividends and interest are not in the trades file, so they aren't counted here.
